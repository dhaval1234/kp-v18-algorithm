**KP v18** is a quantitative algorithmic trading framework designed to maximize profitability by fusing ancient **Krishnamurti Paddhati (KP) astrology**, Hora timing windows, and Tithis with modern risk-managed technical indicators (**RSI, VWAP, and ATR-based dynamic stops**) for Nifty and Bank Nifty.

---

## 💰 Profit Maximization Features

1. **Hora Timing Alpha:** Separates the trading day into high-volatility opening phases and prime-trend acceleration zones to avoid chop and capture directional moves.
2. **ATR Dynamic Stop-Loss:** Automatically calculates risk per trade and scales position size to prevent over-leveraging and protect capital.
3. **Multi-Target Exit Strategy:** Built-in risk-reward ratios (1:2 and 1:3 targets) to lock in profits systematically.
4. **Technical Filter Override:** Uses RSI and VWAP triggers to override astrological bias when markets exhibit high institutional momentum.
