# KP v18 Algorithmic Financial Forecasting Engine

KP v18 is a data-backed predictive system combining Krishnamurti Paddhati (KP) astrology, Hora window timing logic, Tithi classifications, and planetary transits with real-time technical indicators (RSI & VWAP) to project price direction for market indices.

## Setup Instructions
1. Install dependencies: `pip install -r requirements.txt`
2. Run algorithm: `python kp_v18_algorithm.py`
